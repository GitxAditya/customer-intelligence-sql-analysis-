# customer-intelligence-sql-analysis-

> **An end-to-end SQL data analysis project uncovering customer churn risks, product profitability, and marketing attribution anomalies.**

## Project Overview
This repository demonstrates a complete data analytics workflow using **MySQL**. Rather than just writing basic queries, this project simulates real-world business intelligence: asking critical business questions, auditing data integrity, and delivering strategic recommendations to executive stakeholders.

The database (`customer_intelligence_db`) contains over 3.3 million dollars in transaction data, covering Customer Lifetime Value (CLV), Sales Trends, Product Profitability, Inventory Health, and Marketing Funnel performance.

---

## Tech Stack & Skills Demonstrated

| Category | Tools & Techniques |
| :--- | :--- |
| **Database Engine** | MySQL |
| **Environment** | MySQL Workbench |
| **Advanced SQL** | Common Table Expressions (CTEs), Window Functions (`ROW_NUMBER`, `RANK`, `LAG`), Complex Joins, Subqueries |
| **Business Acumen** | Cohort Analysis, RFM Segmentation, Market Basket Analysis, ROI/CPA Tracking, P&L Calculations |
| **Data Quality** | Anomaly Detection, SQL Fanout Identification, Data Auditing |
