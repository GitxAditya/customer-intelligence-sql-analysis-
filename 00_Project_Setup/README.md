# Database Setup

This folder contains everything required to initialize the project database.

## Files

### create_database.sql

Creates the project database.

---

### import_order.md

Step-by-step guide explaining the correct order for importing datasets and executing SQL scripts.

---

## Recommended Setup Sequence

1. Create Database
2. Create Tables
3. Import Excel Data
4. Create Indexes
5. Create Views
6. Create Functions
7. Create Stored Procedures
8. Create Triggers
9. Run Business SQL Reports

Following this order ensures that all foreign key relationships and database objects are created successfully.
